To get started, get yourself registered on Glimpse.

Get your API Keys from the Settings Page. The API Keys redirect auth, so you wouldn't require any more auth tokens separately. The JWTs on Glimpse have generally a 1 day TTL

Go onto Settings Page

Generate your API keys for your bots. All endpoints you would be requiring for bot trading are also mentioned in the doc properly.
